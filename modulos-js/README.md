# Web dinamica.
## Preguntas JavaScript ES Modules.
### 1 ¿Para qué sirve export? ¿Qué pasa si no lo pones?
Para que una función sea accesible fuera de su archivo. Si no está incluido, no es posible hacer import.
### 2 ¿Para qué sirve import? ¿Cómo se indica la ruta del archivo?
Para poder usar funciones de otros archivos.<br>La ruta es indicada mediante un path hacia el archivo.
### 3 ¿Por qué usamos type="module" en el HTML?
Porque es lo que permite al navegador reconocer el import/export.
### 4 ¿Qué ventaja tiene separar el código en varios archivos en un proyecto real?
Que está más organizado, y es más facil de leer.
